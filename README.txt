# SMKN3_Kendal_Laundry

Ini adalah versi project/latihan website sekolah yang dibuat dari referensi tampilan yang kamu kirim,
dengan project `laundry` milikmu ditempatkan di menu:

Lainnya -> Laundry

## Cara menjalankan

1. Extract folder `SMKN3_Kendal_Laundry` ke:
   C:\xampp\htdocs\

2. Pastikan XAMPP:
   - Apache = Start
   - MySQL = Start

3. Buka:
   http://localhost/SMKN3_Kendal_Laundry/

4. Klik:
   Lainnya -> Laundry

## Catatan database

Project laundry yang kamu kirim memakai database MySQL bernama `laundry`.
File zip yang kamu kirim tidak berisi file `.sql`, jadi database lama tidak bisa ikut dipindahkan
secara otomatis.

Project laundry juga memiliki beberapa halaman admin yang direferensikan oleh kode tetapi tidak
ikut ada di zip (contoh: transaksi.php, laporan.php, pelanggan_tambah.php, pelanggan_edit.php,
pengaturan_harga.php, ganti_password.php). Halaman yang memang ada tetap dipertahankan.

Kalau kamu punya database `.sql` dan file PHP yang belum ikut ter-upload, kirimkan juga supaya
bisa digabungkan dengan lengkap.

## Penting

Ini bukan perubahan pada website resmi SMK Negeri 3 Kendal. Ini adalah salinan/project latihan
yang berjalan di localhost milikmu.
